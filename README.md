# Expert

An iPhone and iPad practice tracker built with SwiftUI. Create skills, track focused practice sessions, and review progress toward milestones.

## Features

- Skill creation, renaming, archiving, and deletion
- Practice timer with pause and resume
- Session history, notes, and manual time entries
- Goals, milestones, and practice summaries
- Local reminders, backup and restore, and light/dark appearance
- Local storage without a required user account

## Open the project

1. Open `Expert.xcodeproj` in Xcode.
2. Select the Expert app target and configure your signing team.
3. Review the deployment target for your installed SDK and test device. The current project contains an iOS 27.0 override.
4. Choose an iPhone or iPad simulator or connected device, then build and run.

## Repository layout

- `App/Expert/` — application source and assets
- `ExpertTests/` and `ExpertUITests/` — tests
- `AppStore/` — draft store metadata and review notes
- `Website/` — support and privacy website sources
- `Design/Expert-Sketch-Assets/` — editable SVG design assets and usage instructions
- `Design/Expert-Sketch-Assets.zip` — packaged design assets
